## Why I Chose Option 2

I chose Option 2 because it is similar to the game my team is developing. Both games use a 3D environment, an elevated camera view, and NPC enemies that can detect and eliminate the player. This assignment helps me understand how to build these features for our own game.

## About the Game

Haunted House is a 3D stealth game where the player explores a haunted house, avoids enemies, and tries to reach the exit without being caught.

## How to Run

1. Download or clone this repository.
2. Open the project in **Unity Hub** using **Unity 6.3**.
3. Open the **MainMenu** scene (or **Main** if the menu is not available).
4. Press **Play** in the Unity Editor.
